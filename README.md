# Us · 我们的小世界

两位成员专用的私密 Web 手账，使用 React、TypeScript、Node.js 和 SQLite。浏览器本机预览可体验示例和单人加密空间。开发顺序、架构和验收条件见 [Web 产品设计与开发计划书](docs/US_WEB_DESIGN_AND_IMPLEMENTATION_PLAN.md)。

双人游乐园包含游戏、创造工坊、共建世界和加密作品馆。隔离环境开关、验证命令和 SQLite 升级见 [双人游戏与共创系统](docs/PLAYGROUND_IMPLEMENTATION_STATUS.md)。

微信小程序的历史版本、配置和验证记录见 [实现状态](docs/STATUS.md) 和 [微信提审准备记录](docs/WECHAT-SUBMISSION-20261103.md)。

## 马上查看

### 双人同步网页版

网页同步服务使用 Node.js 22.13 或更高版本和 SQLite。日记和照片在设备上加密后同步。
浏览器需要安全上下文。在服务器本机可用 `http://127.0.0.1:5180/`，其它设备通过 HTTPS 访问。

首次启动，在 PowerShell 中运行以下命令生成两个随机网站密码。
已有 `.env.web` 时沿用原配置。请保管好此文件，并分别向两位成员提供各自的密码。

```powershell
if (-not (Test-Path -LiteralPath .env.web)) {
  $webAccounts = [ordered]@{
    member1 = [guid]::NewGuid().ToString('N')
    member2 = [guid]::NewGuid().ToString('N')
  }
  $webJson = $webAccounts | ConvertTo-Json -Compress
  Set-Content -LiteralPath .env.web -Value "US_WEB_ACCOUNTS='$webJson'" -Encoding utf8
}
npm ci
npm run build:web
npm run serve:web
```

1. 排在配置首位的账号登录网页并创建空间，设置本机解锁口令。
2. 在「我的空间 → 设备与安全」生成邀请码。另一位成员登录自己的账号，输入邀请码并设置自己的本机解锁口令。
3. 加入者看到「已加入双人空间」后，把自己的设备安全码发给创建者。创建者在「我的空间 → 设备与安全」核对安全码，选择对方设备，重新输入网站密码后发送空间密钥，再把自己的设备安全码发给加入者。加入者在等待页面填写创建者的安全码并接收密钥，即可进入共同空间。

同一台电脑测试两个账号时，请使用不同浏览器或不同浏览器配置文件。普通标签页共享网站会话。
已加入的账号在新浏览器可以选择「仅加入共同空间」，向对方请求共享密钥。要在新浏览器读写私人记录，请从仍可访问本人私人记录的设备导出加密密钥备份，再用该账号的备份和恢复密钥还原。
网站的首页、时光、日记详情和编辑、相册、互动、计划和设置支持直接打开及刷新。「我的 → 修改昵称」用于设置两人都能看到的显示名。默认在当前浏览器记住成功解锁 24 小时。在共用设备上可在口令表单取消勾选，使用完毕后锁定或退出网站账号。

在「我的 → 站内陪伴」开启想你、回送和那年今日。这项设置按网站账号保存在当前浏览器。想你在共同空间内同步，双方均可撤回自己发送的内容。

网站密码与本机解锁口令应分别设置。加密密钥备份用于恢复设备解锁。服务端数据库默认保存于 `artifacts/private-web/us.sqlite`，包含同步记录和照片密文。可在服务运行时创建一致性快照，命令要求目标文件尚不存在，目标目录已建立并支持硬链接。

```powershell
npm run backup:web -- 'artifacts/private-web/us.sqlite' 'artifacts/private-web/us-snapshot-20261116-01.sqlite'
```

建议把快照复制到独立备份位置。演练恢复时用快照的工作副本和独立预发布环境，将 `US_WEB_DB` 指向该副本，沿用两位成员的稳定账号名。由两人分别使用各自的密钥备份和恢复密钥确认原有共享、私人记录和照片。切换正式库前须核对快照之后的写入、撤销与删除，保留原库以便回退。

想离线阅读时，从「我的空间 → 导出我的回忆」选择「导出可读图文归档」。选择记录范围和日期，重新输入本机解锁口令。解压下载的 ZIP 后打开 `index.html`。`photos/` 保存空间中已经加密同步的照片版本，`records.json` 保存结构化记录，`manifest.json` 列出范围、数量和未导出的项目。可读归档是明文文件，请存放在你信任的位置。

如果保存时网络断开，重新打开编辑器后可用「核对并继续原保存」查询同一次提交。多人同时修改时，编辑器保留本机内容，允许先查看对方的新版本，再决定是否以新版本为基础保存。新上传且未关联记录的暂存照片保留七天，之后由服务端清理。回收站依然保留已关联照片。
服务重启后需重新登录，网站账号名用于绑定加密空间，应保持稳定。

上线时由 HTTPS 反向代理连接本机的服务端口，并将 `US_WEB_ORIGIN` 设为浏览器使用的 HTTPS 源。
可用 `US_WEB_PORT` 和 `US_WEB_DB` 指定本机端口与数据库路径。当前网站从空白空间开始，原微信日记和照片的迁移需要单独处理。

### 单机预览

```powershell
cd 'E:\双人小程序'
npm ci --registry=https://registry.npmjs.org
npm run dev
```

需要 Node.js ≥22.12.0。打开 <http://127.0.0.1:5173/>，首次使用选择「逛逛示例小世界」。也可以用 PowerShell 7 运行 `启动预览.ps1`。

浏览器提供示例空间和个人本机加密空间。示例中的名字、日期和插画全部是演示数据。两种模式的存储互相隔离；浏览器不连接微信、不跨设备同步。示例凭据仅在当前标签页会话有效，关闭标签页后可重新建立示例。

恋爱日期可从首页天数卡片上的「设置恋爱开始日期」直接修改，也可在「未来清单 / 计划 → 特别的日子 → 恋爱纪念日」中编辑。字段名为「恋爱开始日期」，开始当天计为第 1 天，保存后首页自动重算。

「我的空间 → 连接与同步」可检查当前连接、最近成功刷新时间和可查看的记录数。本机模式只检查本地服务；微信模式检查云函数是否可连接，不能据此证明数据库规则或双人同步已验收。

## 微信开发者工具

1. 准备真实小程序 AppID 和 CloudBase 经典文档数据库环境 ID。
2. 运行 `npm run configure -- --appid wx0123456789abcdef --env 你的环境ID`（替换为真实公开标识）。1.2.6 起，单环境下开发版和体验版调用 `usApiTest`，使用独立数据和测试账号白名单。也可用 `--dev-env 测试环境ID` 连接单独的测试环境。详情见 [部署说明](docs/DEPLOYMENT.md)。工具只写公开配置，请勿传入密钥。
3. 执行 `npm run build`，然后导入本目录的 `project.config.json`。原生 JS 已由 esbuild 打包，无需再在微信工具里构建 npm。
4. 根据 [部署说明](docs/DEPLOYMENT.md) 创建集合、索引、安全规则并部署 `cloudfunctions/usApi`。
5. 按 [双人真机验收](docs/ACCEPTANCE.md) 完成两部手机的测试，再准备发布。

用户已扫码开通云环境，本工程已配置后台核实的公开标识；尚未部署云函数、上传或发布小程序。对其他未配置 AppID / 云环境的检出版本，小程序欢迎页会明确显示配置提示。

## 工程与验证

日常 Web 检查使用 `npm run check:web`。它运行 Web 类型检查、本地回归测试和 Vite 生产构建，不依赖真账号、正式数据库或微信开发者工具。托管集成测试会绑定本机回环的临时端口，在 `artifacts/` 下建立合成账号的临时库，并在完成后清理。GitHub Actions 在 Node.js 24 上运行相同命令。

发布前运行 `npm audit --audit-level=high` 核对锁定依赖的安全公告。该步骤需要访问配置的 npm 注册表。

用独立浏览器会话验证 Web 界面时，先运行 `npx playwright install chromium firefox webkit`，再运行 `npm run test:web:e2e`。本机已有 Chrome 或 Edge 也可用 PowerShell `$env:US_WEB_BROWSER_CHANNEL = 'chrome'` 或 `'msedge'` 选择该浏览器。跨引擎回归覆盖 Firefox、WebKit 与两个账号之间的配对、媒体重编码、断网冷启动、备份互换恢复、设备撤销和仅共同授权设备。离线用例同时断开测试夹具的上游连接：Playwright 的引擎级离线不作用于 Service Worker 会话，只靠它会让页面从服务器取回在线内容。验收使用随机测试账号、合成照片和临时数据库，结果见 [跨引擎与换机验收报告](docs/WEB_ENGINEERING_REPORT_2026-11-20.md)。

生成可部署 ZIP 使用 `npm run package:web`。包内带 `server.mjs`、静态资源、部署配置示例和数据库恢复脚本。具体步骤见 [Web 部署与恢复](docs/WEB_DEPLOYMENT.md)。

下列命令用于历史微信构建、SDK 检查和打包。

```powershell
npm ci --prefix cloudfunctions/usApi --ignore-scripts --registry=https://registry.npmjs.org
npm run typecheck
npm test
npm run build
npm run check:mini
npm run check:sdk
npm run preflight
# 完整执行测试、构建、自检并生成 ZIP 与 SHA256
npm run release
```

`npm run preflight` 将证据写入 `docs/release-readiness.json`，分别报告本地构建和云配置状态。没有云配置时允许本地候选包通过；`npm run preflight -- --require-cloud-config` 会在配置缺失时退出码为 2。二者均不连接真实云环境执行部署验收。

完整流程通过后，`release/` 中生成按版本命名的 ZIP 和 `.sha256`。包内包含源码、构建产物和就绪报告，排除依赖目录、`.env*`、`*.local.json`、微信私人项目配置和本机测试数据。单独执行打包脚本也会检查报告版本和构建产物哈希。

构建输出：`dist/` 是浏览器静态站点；`miniprogram/app.js`、`miniprogram/generated/` 和各原生页面 JS 是微信产物；`cloudfunctions/usApi/index.js` 是云函数入口。

「一起玩耍 → 每日问答 / 默契小问答」可进入题库、自定义提问与历史问题；「我的空间」可开启减少动态效果。网页与原生端共享题库和照片预算逻辑，原生还提供转盘轻震动，需真机验证。恋爱开始日期入口继续保留。

## 当前边界

- 已完成本地构建、自动化测试、原生路由与事件运行时检查，以及浏览器交互检查；这些不等于微信开发者工具和真实 iOS / Android 双端验收。
- 云函数候选使用官方预发布 `wx-server-sdk 5.0.1-beta.1`，固定 `axios 0.34.0` 覆盖其同一 0.x 系列依赖。已做 7 项离线 SDK 包装层检查；审计结果见就绪报告。**这是预发布候选，尚未证明真实 CloudBase、运行时及手机兼容性，不是可直接发布的生产验收结论。** 不要仅按零依赖告警判断是否可发布。
- 语音 / 视频记录、微信订阅提醒与定时任务、小程序内 PDF / 长图、更多游戏、完整家具摆放与成长形态动画仍属于后续迭代。现有界面不伪造这些结果。
- 密钥轮换只保护未来新内容；旧密钥为读取历史保留。撤销设备或关闭空间不能撤回已经下载、解密、截图或导出的副本。
- 本机口令库使用 scrypt（N=32768，r=8，p=1，约 32 MiB）；真实手机上的性能和兼容性尚未验收，密码学时间锁、密码学盲答和独立安全审计均未实现。

本项目没有外部统计脚本或字体请求；插画和图标在本地提供。

关闭空间前请分别保存 v2 加密备份文件和恢复密钥。重新查看或导出需再次验证本机口令；旧备份仍可恢复。双人关闭须双方确认，冷静期可读、可导出、可撤销；到期清理需要按部署说明单独配置维护定时器。本机预览不运行云端定时任务。
