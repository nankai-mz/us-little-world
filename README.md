# Us · 我们的小世界

按设计对话构建的微信原生双人私密小程序：TypeScript + WXML/WXSS + CloudBase，附带能实际操作的浏览器本机预览。视觉采用奶油白、豆沙粉、鼠尾草绿和手绘手账插画。

当前版本为 **1.2.0 本地候选版**。本阶段修复原生模板条件绑定与照片处理，补齐原生页面细节，并完成手账视觉、轻动效、120 个分类话题、24 道默契题和自定义提问。上一阶段的连接、同步、配置与打包能力继续保留。按用户选择，AppID 和云环境保持未配置，尚未部署。可复核结果见 [本地就绪报告](docs/release-readiness.json) 和 [第三阶段交付说明](docs/PHASE3.md)。

## 马上查看

```powershell
cd 'E:\双人小程序'
npm ci --registry=https://registry.npmjs.org
npm run dev
```

需要 Node.js ≥22.12.0。打开 <http://127.0.0.1:5173/>，首次使用选择「逛逛示例小世界」。也可以用 PowerShell 7 运行 `启动预览.ps1`。

浏览器提供示例空间和个人本机加密空间。示例中的名字、日期和插画全部是演示数据。两种模式的存储互相隔离；浏览器不连接微信、不跨设备同步。示例凭据仅在当前标签页会话有效，关闭标签页后可重新建立示例。

恋爱日期可从首页天数卡片上的「设置恋爱开始日期」直接修改，也可在「未来清单 / 计划 → 特别的日子 → 恋爱纪念日」中编辑。字段名为「恋爱开始日期」，开始当天计为第 1 天，保存后首页自动重算。

「我的空间 → 连接与同步」可检查当前连接、最近成功刷新时间和可查看的记录数。本机模式只检查本地服务；微信模式检查云函数是否可连接，不能据此证明数据库规则或双人同步已验收。

## 微信开发者工具

1. 准备真实小程序 AppID 和 CloudBase 经典文档数据库环境 ID。
2. 运行 `npm run configure -- --appid wx0123456789abcdef --env 你的环境ID`（替换为真实公开标识）。工具校验后写入项目配置，不登录、不创建云资源、不部署。不要传入 AppSecret 或 AI 密钥。
3. 执行 `npm run build`，然后导入本目录的 `project.config.json`。原生 JS 已由 esbuild 打包，无需再在微信工具里构建 npm。
4. 根据 [部署说明](docs/DEPLOYMENT.md) 创建集合、索引、安全规则并部署 `cloudfunctions/usApi`。
5. 按 [双人真机验收](docs/ACCEPTANCE.md) 完成两部手机的测试，再准备发布。

这里没有创建你的微信账号、云环境，也没有上传或发布小程序。缺少 AppID / 云环境时，小程序欢迎页会明确显示配置提示。

## 工程与验证

```powershell
npm ci --prefix cloudfunctions/usApi --ignore-scripts --registry=https://registry.npmjs.org
npm run typecheck
npm test
npm run build
npm run check:mini
npm run check:sdk
npm run preflight
# 完整执行测试、构建、自检并生成 ZIP 与 SHA256
npm run release
```

`npm run preflight` 将证据写入 `docs/release-readiness.json`，分别报告本地构建和云配置状态。没有云配置时允许本地候选包通过；`npm run preflight -- --require-cloud-config` 会在配置缺失时退出码为 2。二者均不连接真实云环境执行部署验收。

完整流程通过后，`release/` 中生成按版本命名的 ZIP 和 `.sha256`。包内包含源码、构建产物和就绪报告，排除依赖目录、`.env*`、`*.local.json`、微信私人项目配置和本机测试数据。单独执行打包脚本也会检查报告版本和构建产物哈希。

构建输出：`dist/` 是浏览器静态站点；`miniprogram/app.js`、`miniprogram/generated/` 和各原生页面 JS 是微信产物；`cloudfunctions/usApi/index.js` 是云函数入口。

「一起玩耍 → 每日问答 / 默契小问答」可进入题库、自定义提问与历史问题；「我的空间」可开启减少动态效果。网页与原生端共享题库和照片预算逻辑，原生还提供转盘轻震动，需真机验证。恋爱开始日期入口继续保留。

## 当前边界

- 已完成本地构建、自动化测试、原生路由与事件运行时检查，以及浏览器交互检查；这些不等于微信开发者工具和真实 iOS / Android 双端验收。
- 云函数候选使用官方预发布 `wx-server-sdk 5.0.1-beta.1`，固定 `axios 0.34.0` 覆盖其同一 0.x 系列依赖。已做 7 项离线 SDK 包装层检查；审计结果见就绪报告。**这是预发布候选，尚未证明真实 CloudBase、运行时及手机兼容性，不是可直接发布的生产验收结论。** 不要仅按零依赖告警判断是否可发布。
- 语音 / 视频记录、微信订阅提醒与定时任务、小程序内 PDF / 长图、更多游戏、完整家具摆放与成长形态动画仍属于后续迭代。现有界面不伪造这些结果。
- 密钥轮换只保护未来新内容；旧密钥为读取历史保留。撤销设备或关闭空间不能撤回已经下载、解密、截图或导出的副本。
- 本机口令库使用 scrypt（N=32768，r=8，p=1，约 32 MiB）；真实手机上的性能和兼容性尚未验收，密码学时间锁、密码学盲答和独立安全审计均未实现。

本项目没有外部统计脚本或字体请求；插画和图标在本地提供。
