## 隐私用途填写草稿

以下内容用于后台字段核对，尚未作为完整指引提交。微信会依据上传代码的接口调用情况生成必填项，也需要开发者主动补齐。

| 微信字段 | 实际调用 | 建议用途 |
| --- | --- | --- |
| 选中的照片或视频信息 | `wx.chooseMedia`，仅选择图片 | 在用户主动选择照片后，在本机压缩、加密，保存为私人记录或固定双人空间的共同照片 |
| 选择的位置信息 | `wx.chooseLocation` | 在用户主动选点后记录共同足迹的地点名称与坐标；记录内容在本机加密，不进行后台定位 |
| 选中的文件 | `wx.chooseMessageFile` | 在用户主动恢复备份时，在本机读取和验证所选 JSON 加密密钥备份；不上传该源文件 |
| 剪贴板（平台同时列出读取和写入接口） | `wx.setClipboardData` | 在用户点击复制时，将一次性邀请码写入剪贴板，供其自行发送给另一位成员；当前代码不调用 `wx.getClipboardData` |

还需通过可用字段或补充说明如实披露：云端鉴权使用微信 OpenID；服务器保存账号与空间绑定、设备标识、公钥、时间与版本等必要元数据，以及用户提交内容的密文。日记正文、所选照片和位置记录在本机加密；口令及恢复密钥需按既有设计保存在本机和用户离线备份中。
