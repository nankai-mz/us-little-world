# Us Web 候选版本独立审定

审定日期为 **2026-11-20（北京时间）**。依据为开发计划书第 14 节、交接清单任务 A 至 E、接手 Agent 的工程报告及本轮独立复验。

**裁决：候选包可进入隔离预发布，正式上线暂缓。** 跨引擎核心流程及密文缓存改动已有本机证据。正式 HTTPS、两部实际日用设备和独立主机灾备仍缺放行证据。源码保持接手 Agent 提交时的状态。

## 候选包与复验结果

- 候选为 `us-web-1.2.11-2026-11-19T16-44-29-299Z.zip`，858,152 字节。SHA-256 为 `f173b8d22561de9ca326036e06fb3a2e9d2c886614ef2e1ec0a3c73ec84ad362`。独立运行 Vite、重打包服务端并对照工作树文件，包内 27 个受清单保护的组件全部逐字节匹配。
- Web 类型检查、16 个 Vitest 文件共 113 项测试与生产构建独立通过。针对同一候选 ZIP 重跑 3 项端到端用例，打包 Chromium 双账号主链路、Firefox 150.0.2 与 WebKit 26.4 混合引擎链路，以及 HTTPS 上线冒烟命令均通过。Edge 结果来自接手 Agent 的本地记录。
- 混合引擎实际覆盖空 MIME、带合成 GPS EXIF 的 JPEG 重编码、透明 PNG、两账号换机、拒绝错误恢复密钥和他人备份、撤销后重新登记、仅共同授权设备、跨标签锁定与 WebKit 断网冷启动。WebKit 冷启动证据来自 Windows 的自动化引擎。
- 在全新 Chromium 配置注入旧版 `Blob` 快照和照片密文。独立确认在线和离线快照读取、旧照片读取、作用域隔离、`Blob` 与文本照片混读、快照写回和缓存清理均通过。这项探针直接调用当前源码，使用合成密文载荷。
- 同一候选包在本机 Ubuntu WSL 通过 TLS 启动、快照、恢复后重启及临时 systemd 单元语法检查。恢复候选保留撤销状态和删除墓碑。WSL 环境的系统单元自身报告权限及未知配置项的警告，演练退出码为 0。演练使用合成库，运行于同一开发机。

## 反馈给接手 Agent

| 优先级 | 发现 | 下一轮验收条件 |
| --- | --- | --- |
| P2 | `e2e/web-compat.e2e.ts:120` 对所有浏览器及所有阶段过滤 `Load failed`、`Network request failed` 等通用 `pageerror`，与工程报告描述的 WebKit 导航取消限定不符。独立复跑也记录了 4 条过滤事件，报告只存数量 | 把例外约束到能与 WebKit 预期导航、断网或取消请求关联的事件。保留引擎、阶段、脱敏路径与错误文案，未能归因的页面异常须导致用例失败。重跑混合引擎场景 |
| P2 | 工程报告第 6 节把关闭后重新开启缓存写成通用回退措施。回退到旧包后，受影响的 WebKit 仍会因写入 `Blob` 中止事务，无法重建可用离线缓存 | 在回退手册中写明该引擎回退会失去离线读稿能力，给出临时联机使用和重新切换到修复版本的路径。只有在引擎能够写入 `Blob` 且联机同步后，才能按旧包重建缓存 |
| P3 | 随包跨引擎回归只断言新快照写为文本，未固化已有 `Blob` 快照或照片继续可读的断言。本轮独立探针已通过 | 将本轮探针覆盖的旧快照、旧照片与混合新旧载荷纳入长期回归 |

## 正式放行条件

1. 在真实 HTTPS 目标环境运行冒烟、登录 Cookie 和反代验证，核对站点与候选静态资源哈希一致。记录目标主机持久卷、备份定时器、告警与回退证据。
2. 在 iOS Safari 和 Android Chrome 各使用一部真实设备完成所有适用的 E01–E11 验收，补记后台锁定、选图、软键盘、自动同步、安装、断网重开、弱网和离线队列。按功能范围补齐 E12–E15 的未测路径。当前无旧数据迁移。
3. 在独立主机用两位成员的合成库与备份演练灾备，测量恢复点和用时，核对各自私人记录、双方共同图文，以及撤销、永久删除、照片清理和空间关闭的状态。交付远端 CI 首次通过记录，并复查新版与回退版本的离线边界。
