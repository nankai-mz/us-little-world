# 双人真机验收清单

本清单是待执行的外部验收，不是完成声明。

## 配置与兼容

- 在微信开发者工具编译全部原生页面，核对 WXML 和目标基础库。
- 在真实 iOS、Android 各一台测试随机数、BigInt、UTF-8 中文 / emoji、scrypt 耗时与内存。
- 从冷启动、隐藏超过五分钟、切换 Tab、重新打开微信验证口令锁定和图片临时文件清理。
- 验证云函数 Node 运行时、SDK事务行为、集合索引、数据库与存储拒绝客户端直连。
- 本候选依赖 `wx-server-sdk 5.0.1-beta.1` 预发布版，要求实际 Node ≥20.19.0；核对部署后的 SDK / axios 版本、读写、查询分页、事务回滚、文件上传 / 下载 / 删除和真实 OpenID。离线包装层检查不替代这些项目。

## 连接与异常恢复

- 「我的 → 连接与同步」可检查接口并取得最新记录；未部署、配置错误、网络不可用、协议不匹配时出现明确提示，不显示虚构的同步成功。
- 断网读取最多自动重试一次，超时后结束；保存 / 删除 / AI 不自动重发，连接恢复后先刷新确认结果，再决定是否提交。
- A 刷新期间新增 / 编辑内容，较早的响应不能覆盖刚保存的内容。后发刷新完成后，旧响应不能倒退界面状态。
- 保存或刷新等待期间锁定 / 进入后台超时，延迟响应不能使明文重新出现在界面；解锁后可刷新确认云端保存结果。
- 模拟本机存储配额不足，失败操作不能破坏已保存的数据；界面应明确提示，释放空间后可重试。

## 双人和密钥

- 两个真实微信账号建立空间；第三个账号无法加入。两个并发加入操作只能成功一个。
- 用过或过期邀请码不能重用。已有空间账号不能覆盖绑定。
- 双方核对含两把公钥的安全码，成功交换空间密钥。
- A 创建共同日记和私人日记；B 仅能读取共同内容，包括直接调用 API 的场景。
- 恢复原账号的密钥备份，注册新设备并恢复历史；错误账号 / 恢复密钥不能覆盖已有密钥库。
- 撤销设备后该设备请求被拒绝；轮换后只有已验证设备能取得未来内容的密钥。并发轮换失败者不能写入错误同版本密钥。

## 六个重点功能

- Pet：两端同时喂食，revision 冲突正确重试；属性不丢；重复操作达到限制；长时间不使用不扣减属性。
- Capsule：未来日期不可在正常 UI 打开，到期后可开；双人确认模式要求双方到期并确认。确认这些是业务层限制。
- Map：纯文字地点不触发定位；主动选点和打开外部地图需明确确认；后台无定位。
- Report：月 / 年统计和手工核对一致，不计私人或回收站内容；报告文件可打开。
- AI：先选共同记录、完整预览、单次授权；取消或修改选择会清除授权；私人记录不在选择范围；错误配置清楚报错；结果只在主动保存时加密存储。
- Game：双方不同时在线也可提交并最终揭晓；跳过真心话有效；转盘至少两项，抽取结果来自实际选项。

## 第三阶段新增真机项目

- 验证全部分屏条件正确生效，不出现多个主页面叠加；六个路由的二级页标题正确，返回和切换 Tab 正常。
- iOS / Android 分别选择较大 JPG、透明 PNG、WebP、多选六张，检查压缩后实际每张 ≤512000 字节、方向与画质；失败明确提示且保留前面成功的照片。25 MB 以上输入应被拒绝，不能无限重试。
- 原生照片网格可预览、移除；保存后再打开、编辑历史、共同 / 私人切换、锁定与离开后临时文件清理正确。恢复含旧示例插画的记录时能显示打包 PNG。
- 核对五组 Tab 图标、较深辅助字色、放大字体以及全面屏底部安全区；在窄屏、深色主题和大字号设置下检查可读性与溢出。
- 两端同一天默认问题一致，话题 8 类共 120 条、默契题 4 类共 24 条；自定义问题经刷新可见，旧问题按原日期续答，不覆盖历史或另一人的答案；并发回答遇明确 revision 冲突后合并。
- 转盘常规模式旋转约 1.5 秒，期间不能重复提交或编辑选项；真实微信轻震动成功后结果仍来自安全随机数。减少动效时不旋转；确认该本机偏好可记住。
- 检查爱心呼吸、宠物反馈与圆角属性条、到期信件开启动画；保存失败或未到期开信时不能显示虚假成功。锁定、退出和切换页面后迟到的动画不能恢复明文内容。

## 数据与退出

- 新图片自动压缩至不超过 500 KB，上传在选择可见范围后加密；另一成员不能取得私人文件密文。
- 日记加密草稿、编辑历史、收藏、留言、筛选、回收站恢复与作者永久删除可用。
- 备份文件与恢复密钥离线分开保存；导出明文前有清楚确认。
- 关闭空间后双方不能继续使用已打开页面发起成功读写；不删除另一方私人内容，也不声称撤回已有副本。
- 单独核对云服务商、地图服务、模型服务的隐私说明和保留设置。
