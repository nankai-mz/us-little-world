# 第三阶段：原生修复、轻动效与题库

更新于 2026-11-01（Asia/Shanghai），本地候选版本 1.2.0。范围来自本轮只读审查报告，并由用户明确选择「同时实施 P2 动效、视觉与题库升级」。未配置云环境，未上传微信代码，未提交审核。

## 修复与实现

| 范围        | 本版行为                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| P0 模板     | 修复 70 处原有 `wx:if` 缺失 Mustache；新增模板检查与发布门槛，不再只验证事件存在。                                    |
| P0 照片     | 两端选择较大图片后自动缩放 / 压缩，以实际字节和 MIME 复核至 ≤500 ×1024 字节；最多八次，输入上限 25 MB，失败明确报错。 |
| P1 原生细节 | 照片网格预览 / 移除、二级页动态标题、五组 Tab 图标、示例 PNG、安全区、较深字色与放大辅助字阶。                        |
| P2 手账     | 和纸胶带、拍立得边框、双环头像、爱心呼吸、暖色卡片；保留已有清晰的恋爱日期设置入口。                                  |
| P2 反馈     | 转盘约 1.5 秒旋转与原生轻震动、结果揭晓、宠物爱心 / 喂食反馈和圆角属性条、到期信件开启过渡。                          |
| P2 内容     | 120 个话题 / 8 类、24 道默契题 / 4 类、加密自定义互相提问、历史问题回看与续答。                                       |
| 并发与偏好  | 双人答案在明确 revision 冲突时有界刷新合并，未知网络结果不重发；提供本机「减少动态效果」开关，网页遵循系统偏好。      |

题库入口：「一起玩耍 → 每日问答 / 默契小问答」，其中可切换题库、自己出题、我们的问题。原生互动首页也有直接入口。减少动效入口在「我的空间」。

每日轮换原先按月内日期取余，会在每月一日重置；现按连续日期序号取余。首道旧默契题文字仍保留，历史答案继续使用原 ID 规则和原日期；没有迁移或重加密用户既有记录。自定义问题保存在共同空间密文内，无第三方题库请求。

压缩前后的临时资源均按会话处理，清理不删除用户原始选择文件。编辑中移除照片只改当前表单，不提前删掉可能仍被已保存记录引用的文件。原生照片 URL 由展示层生成，不写回密文记录。

## 验证证据

自动流程：`npm run release`，依次运行完整 Vitest、TypeScript、三端构建、原生源码 / Node VM 检查、官方 SDK 离线包装层检查、依赖审计、自检与版本 ZIP 打包。实际次数、日期、哈希与通过状态以 `release-readiness.json` 为准。

本轮完整测试 64 / 64 项通过（7 个文件）；原生检查覆盖 6 个路由、58 个事件方法、78 处条件绑定及整个原生包（约 1108 KB，1,135,097 字节）。SDK 包装层 7 项离线检查通过。依赖审计仍由每次自检现场执行，结果与时间以就绪报告为准。

新增 15 项定向测试涵盖压缩预算 / 有界尝试 / PNG 缩放 / 文件清理、模板错误检出、展示层映射与标题、题库完整性 / 连续日期轮换、自定义提问 / 历史续答 / 并发答案合并 / 网络写入不重发。完整流程要求覆盖全部测试文件，不能用某个子集的 JSON 报告代替。

独立本机示例空间浏览器验收（没有清空或改写用户原预览数据）：

- 上传测试 JPEG：4,726,742 字节、2400×1800 → 407,226 字节、1280×960；通过 UI 保存并重新打开，图像已加载。
- 120 个话题按类筛出 15 条，默契题按类筛出 6 条；自定义问题与答案保存后可在「我们的问题」重新打开，答案保留。
- 转盘普通模式先显示忙状态并禁用操作，结束后揭晓；减少动效时直接给出结果。宠物抚摸反馈出现爱心，属性与历史同步更新。
- 照片编辑器可移除当前照片；深色主题下题库按钮、分类和主要辅助文字使用对应主题色，主要提交按钮也区分前景色，避免将浅色主题的深豆沙字直接放在深色底上。

- 390×844 视口下有效内容宽度 375 px，首页、题库、转盘无横向溢出；浏览器日志检查无 warn / error。
- 截图证据位于 `artifacts/phase3-*.png`：首页、分类题库、照片回读、宠物。测试照片和截图不进入分享 ZIP。

## 证据边界

此前原生检查漏掉了模板条件语法；现已补上。报告所称 41 处与实际 70 处不同；“所有嵌套索引均不受支持”的判断未证实，本轮只把照片展示改为更简单的字段绑定。没有把浏览器示例图认定为真实微信启动必经路径。

WXML 检查是自建源码检查器，Node VM 是运行时替身，二者都没有调用微信开发者工具编译器。真实 iOS / Android 压缩结果、方向、内存、动效、震动、隐私授权、双人同步、CloudBase 与 AI 仍待执行 `ACCEPTANCE.md`。本版仍使用官方预发布 `wx-server-sdk 5.0.1-beta.1` 和 axios override，不能用本地审计通过代替云端兼容验收。

本轮没有新增头像上传、语音视频、家具摆放、在线追踪或后台定位。用户此前已验收的日期入口、双人平等、自愿互动、客户端加密与明确 AI 授权保持既有规则。
