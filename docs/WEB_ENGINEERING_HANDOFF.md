## 4. 本地复验命令

在 PowerShell 7 中进入项目根目录。浏览器下载使用 Playwright 官方端点，依赖未准备时先按 README 安装。正式校验使用确切的 ZIP 路径。

```powershell
Set-Location -LiteralPath 'E:\双人小程序'
git status --short
git diff --check

$webTmp = Join-Path (Get-Location) 'artifacts\web-check-tmp'
[IO.Directory]::CreateDirectory($webTmp) | Out-Null
$env:TEMP = $webTmp
$env:TMP = $webTmp

npm run check:web
if ($LASTEXITCODE -ne 0) { throw 'Web 源码检查失败' }
node scripts/package-web.mjs
if ($LASTEXITCODE -ne 0) { throw 'Web 打包失败' }

# 使用上一条命令输出的准确文件名替换占位符。
$zip = Get-Item -LiteralPath 'artifacts/web-release/<候选包文件名>.zip'
$expected = ((Get-Content -LiteralPath ($zip.FullName + '.sha256')) -split '\s+')[0]
if ((Get-FileHash -LiteralPath $zip.FullName -Algorithm SHA256).Hash -ne $expected) {
  throw '候选包 SHA-256 与声明不一致'
}
$env:US_WEB_TEST_PACKAGE = $zip.FullName

npm exec --offline -- playwright test e2e/hosted-web.e2e.ts e2e/web-origin.e2e.ts --output artifacts/playwright-web-release
if ($LASTEXITCODE -ne 0) { throw '发布包主链路或上线冒烟失败' }
npm exec --offline -- playwright test e2e/web-compat.e2e.ts --output artifacts/playwright-web-compat
if ($LASTEXITCODE -ne 0) { throw '跨浏览器验收未通过' }
```

本机使用现有 Chrome 或 Edge 时，可设置 `$env:US_WEB_BROWSER_CHANNEL = 'chrome'` 或 `'msedge'` 选择主回归引擎。混合引擎用例用 Playwright Firefox 与 WebKit。启用独立输出目录可以保留不同引擎的报告。发布检查可运行 `npm audit --audit-level=high` 并留存上游查询结果。
